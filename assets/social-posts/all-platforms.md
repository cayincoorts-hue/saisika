## 3. Reddit r/Python
👉 https://www.reddit.com/r/Python/submit

**Title:**
Built a FastAPI + pandas supply chain risk analyzer — completely offline, runs on any laptop

**Text:**
Tech stack: FastAPI backend, React frontend, pandas for data processing, ECharts for visualization, packaged as Electron desktop app.

Key engineering decisions:
- Wide-to-long table auto-melting for supply chain CSV formats
- Business logic computed once, downstream only reads semantic labels
- All warnings collected and surfaced (no silent data loss)
- Full 6-step reasoning trail for every risk score

https://github.com/cayincoorts-hue/saisika
